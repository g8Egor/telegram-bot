# Админ-панель ОСПК

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Создайте файл `.env` в корне проекта и укажите пароль для админ-панели:
```
VITE_ADMIN_PASSWORD=ваш_пароль
```

По умолчанию пароль: `admin123`

3. Запустите проект:
```bash
npm run dev
```

## Доступ к админ-панели

1. Откройте браузер и перейдите по адресу: `http://localhost:5173/admin/login`
2. Введите пароль из файла `.env` (или `admin123` по умолчанию)
3. После входа вы попадете в Dashboard с разделами управления

## Разделы админ-панели

- **Главная страница** - редактирование Hero секции (заголовок, описание, кнопка)
- **О сообществе** - тексты, ценности, цели
- **Членство / Тарифы** - категории членства (в разработке)
- **Новости** - управление новостями и событиями
- **Команда** - управление членами команды
- **Документы** - управление документами (в разработке)
- **Галерея** - управление фотографиями (в разработке)
- **Контакты** - контактная информация (в разработке)
- **Футер** - настройки нижней части сайта

## Сохранение данных

В текущей версии данные сохраняются в `localStorage` браузера. Это означает:
- Изменения видны только в текущем браузере
- При очистке кеша данные вернутся к дефолтным значениям

### Для продакшена

Для реального использования необходимо:

1. **Создать API endpoints** (например, в `pages/api/admin/*` для Next.js или отдельный бэкенд)
2. **Заменить `lib/dataStorage.ts`** на реальные API вызовы
3. **Добавить базу данных** (PostgreSQL, MongoDB, или JSON файлы на сервере)

Пример замены в `lib/dataStorage.ts`:
```typescript
export const dataStorage = {
  getNews: async () => {
    const response = await fetch('/api/admin/news');
    return response.json();
  },
  saveNews: async (data: NewsData) => {
    await fetch('/api/admin/news', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(data),
    });
  },
  // ... остальные методы
};
```

## Структура данных

Все данные хранятся в папке `data/`:
- `data/types.ts` - TypeScript типы
- `data/hero.ts` - данные главной страницы
- `data/about.ts` - данные секции "О сообществе"
- `data/news.ts` - новости
- `data/team.ts` - команда
- и т.д.

Компоненты публичных страниц читают данные через `lib/dataStorage.ts`, который можно легко заменить на реальный API.
